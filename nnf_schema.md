Nrityapath Notation Format (NNF) — JSON Schema v1.0

1. Overview

The Nrityapath Notation Format (NNF) is a structured JSON standard for representing Bharatanatyam choreography. It is generated by the Nrityapath AI agent and used across:
	•	Gemini / Google AI Studio (prompt → JSON)
	•	Google Opus (workflow validation, review, audit)
	•	Nrityapath Prototype (step-by-step visual viewer)
	•	GitHub Examples (reference data for developers)

An NNF output describes:
	•	mode → movement or storytelling
	•	level → dancer skill level
	•	rasa → emotional flavor
	•	steps[] → ordered choreographic units

Each step contains posture, mudra, movement, beats, direction, description, rasa expression, and a teaching note.

NNF is designed to be lightweight, readable, and extensible.

2. Top-Level Object

{
  "mode": "movement",
  "level": "beginner",
  "rasa": "none",
  "steps": []
}

2.1 mode (string)

Indicates the type of user input.
	•	"movement" — short movement description
	•	"story" — narrative or emotional scenario

2.2 level (string)

User’s declared learning level. Determines complexity of steps.

Allowed values:
	•	"beginner"
	•	"intermediate"
	•	"advanced"

2.3 rasa (string)

Dominant emotional flavor for the sequence.

Suggested values:
	•	"none"
	•	"Shringara"
	•	"Veera"
	•	"Hasya"
	•	"Karuna"
	•	"Adbhuta"
	•	"Raudra"
	•	"Bhayanaka"
	•	"Bibhatsa"
	•	"Shanta"

(For the hackathon, Nrityapath mainly uses: Shringara, Veera, Karuna, Adbhuta, Hasya.)

2.4 steps (array)

An ordered list of Step objects.
Each step corresponds to a choreographic unit (typically 1–4 beats).

⸻

3. Step Object Specification

Each element in steps must follow this structure:
{
  "id": "S1",
  "posture": "ARA",
  "hand_mudra": "ALA",
  "movement": "FWD",
  "beats": "2B",
  "direction": "RIGHT",
  "description": "Take two gentle steps forward in Araimandi with Alapadma, facing right.",
  "rasa_expression": "soft inward glance, shy smile",
  "teaching_note": "Keep knees turned out in Araimandi and avoid collapsing the chest."
}

3.1 id (string)

A human-readable step identifier.
Format: "S1", "S2", "S3" …

⸻

3.2 posture (string)

Lower-body or whole-body foundational stance.

Allowed values:
	•	"ARA" — Araimandi (half-sitting)
	•	"SAM" — Samapada (feet together / neutral)
	•	"MND" — Mandi (deep sitting / kneel)

⸻

3.3 hand_mudra (string)

Dominant hand gesture for the step.

Allowed values:
	•	"ALA" — Alapadma
	•	"KAT" — Katakamukha
	•	"TRI" — Tripataka
	•	"PTA" — Pataka

⸻

3.4 movement (string)

Primary movement type.

Allowed values:
	•	"STATIC" — no travel
	•	"FWD" — step forward
	•	"BWD" — step backward
	•	"TURN_L" — turn/face left
	•	"TURN_R" — turn/face right

⸻

3.5 beats (string)

Duration of the step.

Allowed values:
	•	"1B" — 1 beat
	•	"2B" — 2 beats
	•	"4B" — 4 beats

⸻

3.6 direction (string)

Facing direction or travel direction.

Allowed values:
	•	"FRONT"
	•	"LEFT"
	•	"RIGHT"
	•	"DIAGONAL_L"
	•	"DIAGONAL_R"

⸻

3.7 description (string)

A short dancer-friendly explanation (1–2 sentences).

⸻

3.8 rasa_expression (string)

How rasa/emotion is expressed visually (eyes, face, chest, head tilt).
Use "none" if not applicable.

⸻

3.9 teaching_note (string)

Corrective instruction from a guru’s perspective.
Must be specific and actionable.

⸻

5. Example 1 — Simple Movement Input (Mode: movement)

User input (conceptual):

Beginner level, movement mode.“araimandi alapadma, step forward for 2 beats facing right.”

Possible NNF JSON:
{
  "mode": "movement",
  "level": "beginner",
  "rasa": "none",
  "steps": [
    {
      "id": "S1",
      "posture": "ARA",
      "hand_mudra": "ALA",
      "movement": "TURN_R",
      "beats": "1B",
      "direction": "RIGHT",
      "description": "Execute a controlled pivot on the spot to face the right side, maintaining Araimandi with Alapadma.",
      "rasa_expression": "none",
      "teaching_note": "Keep the center of gravity low and avoid rising out of Araimandi during the turn."
    },
    {
      "id": "S2",
      "posture": "ARA",
      "hand_mudra": "ALA",
      "movement": "FWD",
      "beats": "2B",
      "direction": "RIGHT",
      "description": "Take two steps forward (R–L) while facing right, maintaining Alapadma on both hands.",
      "rasa_expression": "none",
      "teaching_note": "Keep knees turned out and place steps cleanly without bouncing."
    }
  ]
}

  "rasa": "shringara",

      "rasa_expression": "Soft, tentative eye contact (Sama Drishthi) followed by a quick, nervous lowering of the gaze.",
      "teaching_note": "Utilize a slight, quick weight shift (Kampa) on the heels to show nervous energy while maintaining the Araimandi depth."
    },
    {
      "id": "S2",
      "posture": "ARA",
      "hand_mudra": "KAT",
      "movement": "FWD",
      "beats": "2B",
      "direction": "DIAGONAL_R",
      "description": "Takes a deliberate, single step forward (Right foot) on a slight diagonal, transitioning both hands to Katakamukha mudra (indicating focus and preparation).",
      "rasa_expression": "A momentary soft focus (Prasanna) in the eyes, showing the decision to approach.",
      "teaching_note": "The forward step should be graceful, not stomping (avoid Tattu Mettu); ensure the transition into Katakamukha is smooth."
    },
    {
      "id": "S3",
      "posture": "ARA",
      "hand_mudra": "TRI",
      "movement": "FWD",
      "beats": "4B",
      "direction": "FRONT",
      "description": "Performs four slow, controlled forward steps (R-L-R-L) using Tripataka mudra in both hands, signaling a graceful approach.",
      "rasa_expression": "Gentle, rhythmic Tala (side-to-side neck movement) to show hesitation mixed with sweetness.",
      "teaching_note": "Maintain a continuous, even flow throughout the four beats; avoid any upward bounce when stepping forward to sustain the intermediate grace."
    },
    {
      "id": "S4",
      "posture": "ARA",
      "hand_mudra": "ALA",
      "movement": "STATIC",
      "beats": "2B",
      "direction": "FRONT",
      "description": "Stops close to the girl, bringing the right hand in Alapadma (representing the flower) and the left hand to Katakamukha near the chest.",
      "rasa_expression": "A slight tilt of the head (Parivrtta Shiras) with a shy, subtle smile.",
      "teaching_note": "Hold the Alapadma gently; the flower representation should be held delicately and not too high or low."
    },
    {
      "id": "S5",
      "posture": "ARA",
      "hand_mudra": "ALA",
      "movement": "STATIC",
      "beats": "2B",
      "direction": "FRONT",
      "description": "The right hand holding Alapadma is smoothly and deliberately extended towards the girl (the offer) and held briefly.",
      "rasa_expression": "The eyes briefly connect with the hand as it extends, then immediately shift to a humble, downcast gaze (Avahittha) to show shyness.",
      "teaching_note": "The extension must be controlled and even; the power of the expression is in the shift of the eye focus immediately following the action."
    }
  ]
}
