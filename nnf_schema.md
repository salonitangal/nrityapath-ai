Nrityapath Notation Format (NNF) — JSON Schema v1.0

1. Overview

Nrityapath Notation Format (NNF) is a JSON-based structure for representing Bharatanatyam choreography generated by the Nrityapath AI agent.

Each output describes:
mode – whether the input was a movement phrase or a story
level – learner skill level
rasa – dominant emotional flavor
steps – an ordered sequence of dance steps, each with posture, mudra, movement, beats, direction, and teaching notes

This format is used consistently across:
Gemini / AI Studio prompt
Opus workflow output
Framer prototype data samples
GitHub examples

2. Top-Level Object

{
  "mode": "movement",
  "level": "beginner",
  "rasa": "none",
  "steps": []
}

2.1 
mode
 (string)
Describes what kind of input the user gave.
"movement" — user entered a short movement description
"story" — user entered a narrative / emotional storyline

2.2 
level
 (string)
User’s learning level. Affects complexity of steps and teaching notes.

Allowed values:
"beginner"
"intermediate"
"advanced"

2.3 
rasa
 (string)
Dominant emotional flavor for the sequence.

Suggested values (not strictly limited):
"none"
"Shringara"
"Veera"
"Hasya"
"Karuna"
"Adbhuta"
"Raudra"
"Bhayanaka"
"Bibhatsa"
"Shanta"

(For the hackathon, you’ll mainly use a subset like Shringara, Veera, Karuna, Adbhuta, Hasya.)

2.4 
steps
 (array)
An ordered list of Step objects.
Each step represents one choreographic unit (1–4 beats).

3. Step Object

Each element in steps has the following structure:
{
  "id": "S1",
  "posture": "ARA",
  "hand_mudra": "ALA",
  "movement": "FWD",
  "beats": "2B",
  "direction": "RIGHT",
  "description": "Take two gentle steps forward in Araimandi with Alapadma, facing right.",
  "rasa_expression": "soft inward glance, shy smile",
  "teaching_note": "Keep knees turned out in Araimandi and avoid collapsing the chest."
}

3.1 
id
 (string)
Human-readable step ID.
Format: "S1", "S2", "S3", …

3.2 
posture
 (string)
Lower-body / whole-body base stance.

Allowed values:
"ARA" — Araimandi (half-sitting)
"SAM" — Samapada (feet together / neutral)
"MND" — Mandi (deep sitting / kneel)

3.3 
hand_mudra
 (string)
Dominant hand gesture.

Allowed values:
"ALA" — Alapadma
"KAT" — Katakamukha
"TRI" — Tripataka
"PTA" — Pataka

3.4 
movement
 (string)
Movement type for the step.

Allowed values:
"STATIC" — no traveling, static pose
"FWD" — step forward
"BWD" — step backward
"TURN_L" — turn left / face left
"TURN_R" — turn right / face right

3.5 
beats
 (string)
Duration of the step in beats.

Allowed values:
"1B" — 1 beat
"2B" — 2 beats
"4B" — 4 beats

(You can extend later, but keep it to these for the hackathon.)

3.6 
direction
 (string)
Facing direction or travel direction.

Allowed values (suggested):
"FRONT"
"LEFT"
"RIGHT"
"DIAGONAL_L"
"DIAGONAL_R"

3.7 
description
 (string)
Short natural-language explanation of the step.
Should be understandable by a dancer or student (1–2 sentences).

3.8 
rasa_expression
 (string)
How rasa/emotion is expressed in the upper body / face in this step.
Example: "gentle eye contact and soft smile".

If there is no strong rasa, can be "none".

3.9 
teaching_note
 (string)
Concrete, actionable correction or tip from a “guru” perspective.
Example: "Keep the elbows lifted, avoid dropping the hands below chest level."

5. Example 1 — Simple Movement Input (Mode: movement)

User input (conceptual):

Beginner level, movement mode.“araimandi alapadma, step forward for 2 beats facing right.”

Possible NNF JSON:
{
  "mode": "movement",
  "level": "beginner",
  "rasa": "none",
  "steps": [
    {
      "id": "S1",
      "posture": "ARA",
      "hand_mudra": "ALA",
      "movement": "TURN_R",
      "beats": "1B",
      "direction": "RIGHT",
      "description": "Execute a controlled pivot on the spot to face the Right side, maintaining the Araimandi posture and Alapadma mudra.",
      "rasa_expression": "none",
      "teaching_note": "Keep the center of gravity low and stable; avoid rising up out of Araimandi during the turn."
    },
    {
      "id": "S2",
      "posture": "ARA",
      "hand_mudra": "ALA",
      "movement": "FWD",
      "beats": "2B",
      "direction": "RIGHT",
      "description": "Take two steps forward (R-L) in the new right-facing direction, keeping the Alapadma mudras held out to the sides.",
      "rasa_expression": "none",
      "teaching_note": "Focus on clean foot placement, ensuring the knees are still turned out as the step is taken."
    }
  ]
}
